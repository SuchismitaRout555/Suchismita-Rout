#CustomLandingPage

Custom Shopify page built from scratch (no Dawn sections used), with two custom sections and a dynamic product quick-view popup.

Features:
Banner section — all text editable from the customizer, animated buttons.
Product Grid section — 6 blocks, each with a product picker in the customizer.
Quick View popup — shows name, price, description, and variants rendered dynamically from product data. Add to Cart works via Shopify's Cart AJAX API.
Cross-sell rule — adding a product with variant Black/Medium automatically adds "Soft Winter Jacket" to the cart too.
